About This Project

An agentic AI system for automated CV and LinkedIn profile evaluation with security hardening against prompt injection attacks. Detects hidden white text, encoded manipulation attempts, unicode tricks, keyword stuffing, and fake endorsement patterns. Uses weighted scoring across technical skills, experience depth, domain relevance, and behavioral indicators to provide objective candidate assessment.
