About This Project

This demo showcases an AI-powered recruitment screening system that evaluates candidate profiles across multiple dimensions. The system is designed to detect adversarial inputs including keyword stuffing, hidden text prompt injections, and other manipulation attempts that could bias automated screening tools.

Built with a defense-in-depth approach: layered content analysis, semantic consistency checks, and adversarial input detection work together to produce trustworthy candidate assessments even in the presence of deliberately crafted attack vectors.
