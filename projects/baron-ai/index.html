About This Project

Baron AI is a comprehensive pentesting automation platform built on Kali Linux with a multi-agent architecture. The core engine, BaronLLM-v2, was self-quantized to 4-bit precision. Four specialized agents collaborate: Mr. Smith orchestrates operations, Lily handles cybersecurity strategy, QWEN generates code and payloads, and Gemma humanizes output for readability. A local vector database with RAG pipeline provides MITRE ATT&CK framework-informed strategy generation.
