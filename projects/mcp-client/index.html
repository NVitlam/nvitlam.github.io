About This Project

A custom MCP (Model Context Protocol) client built on the 5ire open-source platform. Designed to connect up to 1,000 MCP servers simultaneously, caching all tool registries and relaying capabilities through a single unified connection to Agent Smith's backend. Handles tool discovery, registration caching, and request routing across stdio, SSE, and WebSocket transports.
