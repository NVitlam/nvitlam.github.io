About This Project

NIRA (Natural IVF Response Assistant) is a conversational AI prototype designed to support patients navigating the IVF process. It provides clear, empathetic answers to common fertility treatment questions while always encouraging patients to consult their care team for personalized guidance.

This demo showcases a chat-based interface with pre-composed clinical responses. In a production system, responses would be generated by a fine-tuned language model with retrieval-augmented generation grounded in peer-reviewed reproductive medicine literature.
